# 🌾 RaithaSetu AI
## Smart Agricultural Workforce & Marketplace Platform

RaithaSetu AI is a smart agriculture platform designed to connect farmers, agricultural workers, traders, and agro-store users through a unified digital platform.

The platform brings together agricultural workforce management, crop marketplace services, location-aware features, AI-assisted agricultural guidance, and English/Kannada support in one place.

## 🎯 The Problem

Farmers and agricultural workers often depend on disconnected methods to find workers, discover agricultural opportunities, connect with buyers, and access farming-related information.

RaithaSetu addresses these challenges by bringing important agricultural services into a single digital platform.

---

## 💡 Our Solution

RaithaSetu connects the major participants of the agricultural ecosystem:

- **👨‍🌾 Farmers** — Post agricultural jobs, find workers, list crops, connect with buyers, and access AI assistance.
- **👷 Agricultural Workers** — Discover suitable agricultural jobs and manage job offers.
- **💼 Traders / Buyers** — Discover available crops and interact with farmers through offers and negotiations.
- **🏪 Agro Stores** — List agricultural products and manage product-related activities.
- **🤖 AI Assistant** — Provides agricultural guidance and intelligent assistance.

---

## ✨ Key Features

### 🤝 Agricultural Workforce Matching
Helps farmers find suitable agricultural workers based on relevant factors such as:
- Skills
- Location and distance
- Availability
- Rating
- Work experience

### 👷 Worker Job Management
Workers can:
- Discover agricultural opportunities
- Receive job offers
- View relevant job details
- Accept or decline offers
- Track job-related activity

### 🌾 Crop Marketplace
Farmers can list harvested crops and connect with registered buyers.

### 💰 Offer & Negotiation System
Farmers and buyers can interact through price offers and counter-offers.

### 🏪 Agro-Store Marketplace
Agro-store users can list agricultural products including:
- Seeds
- Fertilizers
- Pesticides
- Farming tools

### 📍 Location-Based Services
Uses location information to support relevant agricultural services and worker discovery.

### 🌐 English & Kannada Support
Provides bilingual support in:
- English
- Kannada

### 🔐 Authentication & Security
The platform uses:
- JWT authentication
- bcrypt password hashing
- Role-based access control

## ⚙️ Local Development

### Prerequisites
- Node.js
- MongoDB or MongoDB Atlas
- Git

### 1. Clone the Repository
```bash
git clone https://github.com/Srinivash333/RaithaSetu.git
cd RaithaSetu
```

### 2. Backend Setup
```bash
cd backend
npm install
```
Create a `.env` file using `.env.example` and configure the required environment variables.
Start the backend server.

### 3. Frontend Setup
Open a new terminal:
```bash
cd frontend
npm install
npm run dev
```
The Vite development server will display the local URL in the terminal.

🔒 *Never commit API keys, passwords, database credentials, JWT secrets, or other sensitive information to GitHub.*
